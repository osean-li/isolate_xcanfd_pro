# 术语表

> 看教程时遇到不懂的词，来这查。按拼音 / 英文首字母排列。

| 术语 | 含义（白话版） |
|------|----------------|
| **PCB** | 印刷电路板，板子的实物。原理图说「谁连谁」，PCB 把它变成铜皮走线。 |
| **原理图（Schematic）** | 表示「谁和谁电气连通」的逻辑图，不是真实长相。 |
| **位号（Designator）** | 元件编号，如 R1、U1。首字母代表类型（R 电阻 / C 电容 / U 芯片 / D 二极管 / X 晶振 / CN 连接器 / H 排针 / SW 开关）。 |
| **封装（Footprint）** | 元件在 PCB 上的焊盘形状，比如 C0603 表示 0603 规格的两个焊盘。 |
| **网络（Net）** | 原理图里被连在一起的所有点，物理上同一根线。网络名相同 = 电气连通。 |
| **GND** | 地，电压的 0 基准 / 回流路径，可理解为「公共下水道 / 海平面」。 |
| **ISO_GND** | 隔离地，和 GND **不连通**，是实现隔离的关键。 |
| **LDO** | 低压差线性稳压器，降压芯片，原理像「可调水龙头」。 |
| **DC‑DC** | 开关电源，效率高，可升 / 降压。本板 U2 是隔离型 DC‑DC。 |
| **隔离（Isolation）** | 让信号过、电不过，防高压串入电脑。本板额定 1500V。 |
| **CAN / CAN FD** | 汽车 / 工控通信总线；FD 是加速版（数据段最高 8Mbps）。 |
| **差分信号** | 用两根线的电压差表示 0/1，抗干扰强（CAN、USB 高速都用它）。 |
| **阻抗（Impedance）** | 高频下「线看起来像多少欧姆」。USB 差分对要求 **90Ω**。 |
| **差分对** | 一对等长等距走线（如 USB DP / DM）。 |
| **过孔（Via）** | 打通各层、换层的金属小孔，像立交桥。 |
| **丝印（Silkscreen）** | 板子表面白色的字（R1、U1 等），方便焊接维修。 |
| **阻焊（Solder Mask）** | 绿色（或其他色）的漆，盖住不需焊接的铜，只在焊盘开窗。 |
| **退耦电容** | 紧贴芯片电源脚的小电容，像给芯片配个「小水库」，电压一抖就补上。 |
| **终端电阻** | CAN 总线两端各 120Ω，吸收信号反射。本板内置 R8 / R9 并用 SW2 切换。 |
| **TVS** | 瞬态抑制二极管，遇浪涌瞬间把高压泄放到地。 |
| **ESD** | 静电保护二极管，防人体静电打坏敏感引脚。 |
| **晶振（Crystal）** | 极精准的「节拍器」，给 MCU 提供主时钟（本板 24MHz）。 |
| **QFN** | 四边无外露引脚、底部有散热焊盘的封装，最易虚焊，本板主控即 QFN‑48。 |
| **DRC** | 设计规则检查，打板前必跑，自动扫短路 / 开路 / 线宽间距。 |
| **DFM** | 可制造性设计，让工厂好做、良率高。 |
| **爬电 / 间隙** | 隔离所需的最小表面距离 / 空间距离，决定 1500V 会不会击穿。 |
| **叠层（Stack‑up）** | 多层板的铜层 / 介质排列，如 Top / GND / PWR / Bottom。 |
| **ISP** | 在系统编程，本板指「按住 BOOT 进烧录模式」。 |

> 给小白的最后一句：硬件不是背出来的，是「拆 + 看 + 焊」出来的。看不懂就对照编辑器里真实打开的板，一个元件一个元件点开看属性，很快就通了。
