## 焊接顺序建议（边焊边学，防炸板）

> 两套思路，按目标选。**当前是边学边做的原型，建议用方案 2**。完整对照见 [`hardware-knowledge-applied.md` 知识 6](hardware-knowledge-applied.md)。

### 方案 1：量产 / 整洁优先（小 → 大 → 热敏感最后）
- 先焊**最小的被动件**（电阻、电容、二极管）：板子平放，小元件好固定、不易移位。
- 再焊**大件**（接插件、散热片、变压器）。
- 把**热敏感的贵芯片**（MCU、CAN 收发器、传感器）留到最后，避免反复受热损伤。

### 方案 2：原型 / 调试优先（你现在的做法，推荐）
- 先焊 **电源部分** → 上电测电源轨 → 确认没短路、电压对 → 再焊 MCU 等贵芯片。
- 最大好处是**保护贵重器件**：万一电源有问题，烧的是几毛钱的 LDO，不是几十块的 MCU。对"边学边做、怕炸板"的新手是最稳的策略。**这个习惯不用改。**

### 折中方案（担心先焊大件板子不平时）
先焊最小的被动件 → 再焊电源并测轨 → 然后中件 → 最后才焊 MCU / 收发器 / 接插件。
接插件、机械支撑件（USB-C 座、螺丝柱）放最后焊，板子全程能平放操作。

### ⚠️ 焊完电源，别急着焊全套——先上电
用万用表蜂鸣档量 `VCC–GND` 有没有短路，再量各路输出电压对不对。这一步能救你很多板子。
