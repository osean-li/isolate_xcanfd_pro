# HPM5321 高速隔离 USB-CAN FD 工具 — 焊接完整版指南

> **本指南版本对应 PCB：`isolated XCANFD-PRO 20260117V1 @FanhaoCloud`**（即嘉立创 EDA 截图右上角的 3D 板）
> **BOM 数据源**：[`docs/bom.md`](bom.md)（实测导出 26 种料）
> **适用人群**：愿意自己手焊、想一边焊一边学硬件的人（你现在的状态）；也兼容「全部买件 → 找 SMT 厂」的量产场景。
> **核心原则**：**先焊电源，量好再上贵芯片**。一炸板动辄几十块 HPM5321，量一分钟电省一个 MCU。

## 0. 这块板子比你想象的难，提前打预防针

这块板子不是 Arduino 那种「几颗 LED 一个 MCU」的难度，**属于嵌入式进阶**：

| 难度项 | 说明 |
| --- | --- |
| QFN-48 主控 | 底部散热焊盘 + 0.5mm 周边引脚间距，必须热风枪 + 助焊膏 + 锡膏回流，新手头几次空焊 / 连锡几乎必然 |
| 隔离 DC-DC | 模块化封装（U2 B0505S-1WR3），但有方向、还有原副边隔离距离要求，错了就 1500V 失效 |
| 多通道高速 | USB 2.0 高速差分 90Ω、CAN 差分 120Ω，阻抗线已经画在 PCB 上，**焊接不能桥接差分对** |
| 双地系统 | USB 侧 GND 与 CAN 侧 ISO_GND 物理隔开，跨隔离边界走线是禁忌 |

> **心理预期**：第一块板空焊 / 翻车概率 30%~50% 正常；第二块就稳了；别第一块炸了就觉得硬件难。

| 防静电手环 | 必备 | MCU / 收发器都比较怕静电 |

### 2.2 测试仪器
- **万用表**（最低）：测电压、通断、短路
- **示波器**：不在则 USB 通信判断用 PCAN-View 等上位机替代
- **逻辑分析仪**：CAN / SPI 协议解析，本项目其实用得不多

### 2.3 环境
- 工作台铺防静电垫或硬纸板（防板子滑动）
- 良好通风（焊锡烟雾别直接吸）
- 光线充足（QFN 脚几乎看不见）

### 2.4 没有防静电手腕带？—— 平替防静电方案（焊 IC 前必看）

> QFN 主控（U1）、隔离器（U5）、CAN 收发器（U3/U4）都很怕 ESD。**没有手腕带绝不代表可以徒手硬上**——下面这套平替方案能把静电风险压到很低，成本几乎为零。核心思路只有一个：**让"你的身体"和"芯片/PCB"始终处于同一电位（都接到真正的地）**。

**① 让身体先放电 + 保持接地（替代手腕带）**
- 焊接前，先**用手摸一下自来水管 / 暖气片 / 插着电的台式机机箱金属外壳 / 接地的金属窗框**（任一真正接地的金属体）2~3 秒，把身上静电放掉。
- 整个焊接过程中，**每隔一会儿就再摸一下**这个接地金属体（比如每次拿新元件前）。这比戴手腕带简单，但效果接近——关键是"持续把身体电位拉到地"。
- 如果工作台边有**插着电的台式机**，直接把**小一字螺丝刀搭在机箱金属外壳上**，手一直扶着螺丝刀柄金属部分即可（柄是绝缘的，安全），等于一个"临时手腕带"。

**② 工作台也接同一个地（可选但推荐）**
- 铺一张普通纸板/杂志页在桌面上（防滑动），上面再放 PCB。若手头有铝箔，把铝箔摊平铺在桌面，边缘用导线/夹子连到上面的接地金属体，PCB 放铝箔上——整片工作区同电位。

**③ 工具接地（比手腕带更关键）**
- **烙铁**：必须用**三线插头**的温控烙铁。焊前用万用表测「烙铁头 ↔ 电源插头地线脚」应**导通（低阻）**。若不通，说明烙铁没接地，ESD 风险高，不要用它焊 IC。
- **热风枪**：用三线插头机型，外壳/支架金属部分接地。热风枪本身不碰芯片，但手柄若带电会通过您身体传导。
- 所有 IC 元件**只放防静电袋/泡棉上**，别直接扔普通塑料/泡沫（这类材料极易积累静电）。

**④ 操作习惯（同样重要）**
- 拿芯片时**只碰边缘/EPAD 背面，绝不碰引脚**；取芯片前先按 ① 放电。
- 干燥天气（冬天/空调房）尤其危险，可在旁边放一碗水增加湿度，或先喷一点防静电喷雾。
- 别在化纤地毯、毛衣、塑料袋旁边操作。

**⑤ 最低可行组合（预算为零也能做）**
摸一下接地金属体放电 + 三线插头烙铁（头子确认接地） + 只碰芯片边缘 + 干燥环境加湿。这四步加起来零成本，对 QFN 这类敏感芯片足够防住大部分 ESD 击穿。

> 💡 真实教训：本板有用户手焊 U1 时**未做任何防静电**，结果 HPM5321 多个电源脚（5/6/9/34）对 VSS 全部击穿报废，整颗芯片得换。换新时务必按上面 ①~⑤ 做，否则新芯片可能再坏一次。

## 4. 焊接顺序（按元件型号 / 料盘分组，同型号一次焊完）


**为什么"同型号一次焊完"在这里合理？**
- 电阻 / 电容 / 二极管 / 电感 / 晶振 / 连接器都是**无源或结构件，不通电不危险**，
  一次性焊完既省找料、又不会出问题——这正是你要的"少反复找芯片"。
- 真正"怕焊错伤件"的只有 4 类 IC：**U2（隔离 DC-DC）、U5（隔离器）、U3/U4（CAN 收发器）、U1（主控）**。
  把它们按"关卡"卡在中间即可：**先验证 U2 隔离没问题 → 再焊隔离侧 IC（U5/U3/U4） → 最后焊最贵最难的 U1**。
  这样既享受"批量拿料"的效率，又不牺牲"早发现问题"的安全性。

#### 0603 / 0805 / 0402 阻容「7 步法」（首次定义，后续复用）

> 电阻和电容通用、无方向、无极性。这是整份指南最基础的手法，第一次完整写一遍，后面 组2/组3 直接"复用本 7 步法"。

1. 目标焊盘薄涂一层焊油（0603/0402 焊盘小，焊油要少）。
2. 其中一个焊盘**预上锡**（极薄一层，堆厚了会垫高元件）。
3. 镊子夹元件**侧面**（别夹两端，容易弹飞），摆上对齐两个焊盘，轻轻压平。
4. 烙铁熔预上锡端 → 元件定位。
5. 焊另一端：烙铁尖同时碰焊盘 + 元件端头，左手送极少量锡丝，锡包住端头即可。
6. 回焊第 1 端补一点锡，让两端焊点对称饱满。
7. 显微镜 / 手机微距检查：焊点光亮、元件贴合板面、无桥锡、无偏移。

> 💡 电阻电容分不清时：看 PCB 丝印位号——**C 开头焊电容位、R 开头焊电阻位**。放反了不会炸，但功能错。

> ⚙️ **为什么 100nF 用了 16 颗、还要 1µF/10µF/22µF 多种？**（PCB 设计硬知识，别只焊一种）
> 实际电容 = 理想 C ＋ ESL ＋ ESR，构成串联谐振，自谐振 `SRF = 1/(2π√(ESL·C))`，每个电容只在 SRF 附近阻抗最低。
> - **100nF**：SRF ≈ 20–40 MHz → 滤 IC 开关的 **MHz 级高频毛刺**，必须紧贴 IC 电源脚（少一颗对应脚就可能抖、CAN 报错、USB 枚举失败）。
> - **1µF**：SRF ≈ 2–4 MHz → 给 LDO 反馈环路做**中频段相位补偿**（不补可能振荡）。
> - **10µF**：SRF ≈ 0.4 MHz → 应对 USB 端**突发电流**（远端储能）。
> - **22µF**：HPM5321 内核 DCDC 输出滤波。
> - **22pF**：晶振负载电容，和 X1 一起决定 24MHz 起振。
> 多种并联 = 共同覆盖 10 kHz ~ 100 MHz 全频段。少了任何一座，对应频段噪声没人管。

#### U2（B0505S-1WR3，PWRM-TH 直插）

![U2 B0505S-1WR3 隔离 DC-DC](元器件照片/B0505S-1WR3.jpg)

> **U2 引脚封装图（数据手册）**：`1=-Vin`、`2=+Vin`、`3=-Vout`、`4=+Vout`，开口朝下从左到右，1 脚有圆点标识。
> ![U2 B0505S-1WR3 引脚封装图](images/B0505S-1WR3_package.png)

> **单列直插封装（SIP）**：信号脚从左到右固定为 `1=-Vin`、`2=+Vin`、`3=-Vout`、`4=+Vout`。**注意：这与旧版文档中的写法相反**，请务必以立创数据手册（C7465178）截图为准。实物常见 4 脚（SIP-4）；若你看到 **5 个焊脚**，第 5 个是**外壳/屏蔽脚 `Case`**（在最外侧），不参与电路，忽略即可——信号脚 1~4 的位置和定义不变。**有方向**，PCB 丝印上一定标了 1 脚（圆点 / 数字 "1" / 缺口），对齐再焊——**方向焊反会导致 U2 输出异常、甚至烫手烧毁**。
>
> **引脚排布（俯视，开口朝下，从左到右）：**
> ```
>         ◯ ← 顶面小圆点 = 1 脚方向标识
>   ┃1┃  ┃2┃  ┃3┃  ┃4┃   (若见第 5 脚在最外侧 = Case 外壳，忽略)
>   -Vin +Vin -Vout +Vout
>   USB-  5V   CAN侧 隔离5V
>   GND   输入  GND   输出
> ```

**焊接步骤（烙铁 + 焊油）**：
1. 对照照片 + PCB 丝印确认 1 脚方向（丝印圆点对齐芯片 1 脚标记）。
2. 元件从 **TOP 面**插入，引脚穿过 PCB 焊盘孔，轻轻压到底（模块外壳贴紧板面，别留缝）。
3. 翻到**背面**，烙铁 340°C，每个引脚焊 2~3 秒，送锡丝让锡**饱满包住引脚并填满孔**。
4. 剪脚（留 1~2mm）或保留长脚都可。
5. 显微镜/目视检查 4 脚：锡爬满孔、无虚焊、相邻脚不桥锡。

> **顺手焊 C26（10μF，文件名 `106`）**：这是 U2 隔离 5V 输出的滤波电容，和阶段 1 的 C6/C25 同料同容值，只是摆在隔离侧。复用「7 步法」焊接，位置紧贴 U2 输出侧（`+Vout` / `-Vout` 引脚 3/4 附近）。**注意：C26 属于本组，组 2 不再重复列它。**

#### 🔑 关卡 A：上电验证隔离 5V + 隔离成立（最关键）

**① 焊完短路检查（上电前）**

| 检查项 | 方法 | 期望 |
| --- | --- | --- |
| 蜂鸣测 U2 相邻引脚 | 1-2、3-4 之间 | **不响**（内部是变压器隔离，原边副边本就不通） |
| 蜂鸣测 VIN 对地 | 黑笔 GND，红笔量 -Vin / +Vin | `-Vin` 接 USB 侧 GND（响正常），`+Vin` 是 5V（不响） |

**② 上电测试（5V 充电器，别插电脑）**

| 测试点 | 期望 | 说明 |
| --- | --- | --- |
| U2 的 `+Vin(2)` ↔ `-Vin(1)` | **5.0V**（来自 USB 侧） | 确认隔离模块输入到了 |
| U2 的 `+Vout(4)` ↔ `-Vout(3)` | **5V ± 0.25V**（4.75~5.25） | 隔离输出成立 |

**③ 🔑 关键隔离检查（最核心）**

> 万用表**电阻档 / 蜂鸣档**，一头搭 **USB 侧 GND**，另一头搭 **U2 副边 `-Vout(3)`**：
> - **应该不导通（OL / 不响）** ← 正常，隔离成立
> - **如果导通（蜂鸣响）** = 隔离没隔开 = 板子出问题，先断电查 U2 方向 / 周边是否意外连地

**异常处理**

| 现象 | 多半是 | 怎么办 |
| --- | --- | --- |
| 输出 0V | 输入 5V 没到 / 方向焊反 | 量 `+Vin(2)` 有没有 5V，没有查 USB 接线；有 5V 仍 0V 查方向 |
| 输出偏差大 / 模块发热 | 输出滤波或负载问题 | **立刻断电**，核对 U2 周边滤波电容是否漏焊（C26） |
| 隔离检查导通 | U2 方向错 / 副边意外接地 | **立刻断电**，重新核对 1 脚方向 |

> ✅ 关卡 A 通过 = 隔离 5V 真的隔开了。可以放心焊下一组的隔离侧 IC（U5/U3/U4），它们由这个隔离 5V 供电。

**地脚：仅中间 EPAD（脚 49 = VSS）** —— QFN-48 **没有外围独立 VSS 引脚**，GND 全部集中在底部散热焊盘。焊 U1 后若出现「3V3 对地短路 / 装芯片就掉到 0V」，最大嫌疑是 **EPAD 锡量过多受热溢出到左侧脚 5/6/7 一带，把 3V3 与 GND 短接**。处理：拆芯片 → 用吸锡带把 EPAD 彻底吸平（低于四周引脚焊盘）→ 重焊时 EPAD 只涂极薄一层锡、四周引脚极少锡、热风后烙铁+焊油拖锡清桥。

**方法 A（热风枪 + 锡膏，推荐）**：
1. PCB 焊盘涂均匀一层**薄**锡膏（钢网最好；没有就用刮刀/牙签薄涂，切忌堆太厚 → 必桥）。
2. HPM5321 用镊子摆上去，**注意第 1 脚**（点标记 / 切口 / 丝印），对齐 PCB 1 脚。
3. 对好位置后，热风枪 **350°C**、中档风、**画小圆**加热整个芯片。
4. 等看到锡膏**整体反光熔化**，芯片会自动「归位」（QFN 自对中效应）。
5. **关键：加热时间不超过 90 秒**，否则塑料基板会鼓包变形。
6. 冷却后，烙铁 / 吸锡带处理可能桥接的脚（即使锡膏回流好也建议显微镜下检查四角）。

**方法 B（烙铁 + 助焊膏，慎用）**：
1. PCB 所有焊盘涂助焊膏。
2. 芯片摆上，对好 1 脚。
3. **刀口烙铁 + 大量焊锡**沿一边拖焊，靠锡张力让锡爬过每个脚。
4. 拖完 4 边后，显微镜看有没有桥；桥了的用吸锡带吸走再补锡。
5. **底部散热焊盘**：从 PCB 背面能看到焊盘空窗，**单独补锡**（这一步新手最常漏，导致散热不良、芯片过热）。

> **不论 A 还是 B，做完用万用表二极管档量每个相邻引脚之间是否短路**。QFN 一旦桥锡，第一帧 USB 都发不出去。

#### 🔧 实战踩坑：HPM5321 第 6 脚（VIO_B00）对地击穿的真实案例（2026-08）

> 这是一位用户手焊 U1 后真实踩过的坑，整理出来避免你重蹈覆辙。

**现象（一步步排查记录）：**
1. 第一次整板量第 6 脚（VIO_B00）对 GND → 蜂鸣**持续响**，电阻档 0.5~0.9Ω **死死不动**（非电容，是真短路）。
2. 拆下 U1，量**空 PCB** 第 6 脚焊盘对 GND → **不响**（证明 PCB 本身、3V3 走线、去耦电容都正常）。
3. 单独测**芯片**第 6 脚对 EPAD(VSS) → 蜂鸣响、0.9Ω 不动（说明不是桥锡，是芯片本体坏）。
4. 进一步全面测芯片：第 **5 / 6 / 9 / 34 脚**（VDD_SOC 与 VIO_B00 电源域）对 EPAD **全部响/短路**，而第 30 脚 VREFL 响是正常接地。→ 结论：**整片电源域（VDD_SOC + VIO_B00）对 VSS 内部击穿，芯片整体报废**。
5. 用户自述焊接顺序：先焊 LDO 并上电确认 3.3V 正常（此时 U1 未焊），**然后断电再焊 U1**；焊 U1 时**没有做防静电**（无手腕带、工具未确认接地）。

**根因判断：**
- 焊 U1 时**断电**，所以不是"上电烧"；空 PCB 不响，所以不是 PCB 侧短路拉坏。
- 多个电源脚一起对地短路 = 芯片内部电源结构整体击穿，最可能是**焊接时 ESD 静电击穿**或**热风枪温度过高/吹太久过热损伤**（该用户热风枪原本设 350°C、8 挡风速第 4 挡，偏热偏猛）。单脚坏像 ESD，多脚一起坏更像热 + ESD 叠加。
- ⚠️ 注意：用户第一次单独测芯片说"第 5 脚不响（好）"，后来认真重测发现第 5/9 脚其实也响——**QFN 引脚小、侧面氧化或表笔压偏都会导致误判，测电源脚务必认真点对、必要时多测几次**。

**换新前必做（避免新芯片再坏）：**

- [ ] **空 PCB 确认 3V3 干净**（断电、蜂鸣档）：
  - 第 5/9 脚 VDD_SOC 焊盘 → GND：**不响**
  - 第 6/34 脚 VIO_B00 焊盘 → GND：**不响**（本板已确认第 6 脚不响 ✅）
  - LDO1 输出 VOUT 焊盘（ME6211 第 5 脚）→ GND：**不响**
  - 全部不响才焊新芯片。
- [ ] **严格防静电**（无手腕带看下方 §2.4 平替方案）：手腕带接地 + 三线工具接地，只碰芯片边缘。
- [ ] **热风枪降参数**：350°C → **320~330°C**，4 挡 → **2~3 挡**，单颗芯片加热 **≤20 秒**，画圈均匀加热别单点猛吹。
- [ ] **EPAD 薄锡托正**：底部散热焊盘只涂极薄一层锡，把芯片托住居正，减少第 6 脚这类贴边电源脚桥锡/下沉。
- [ ] **焊完先断电测新芯片**第 5/6/9/34 脚对 EPAD：全都应**高阻不响**，才上电。
- [ ] **首次上电串限流**，摸 U1/LDO 不发烫、电流正常再继续。

**判断"芯片坏 vs 桥锡 vs PCB 短路"的三步法：**
1. 整板量某电源脚对 GND 响 → 先拆芯片。
2. 量**空 PCB** 同脚焊盘对 GND：不响 = PCB 好；响 = PCB 侧 3V3 短路（查去耦电容/铺铜）。
3. 量**芯片**该脚对 EPAD：不响 = 芯片好（之前是焊接桥锡，清桥锡即可）；响且阻值稳定不动 = 芯片内部击穿报废，换新。

#### 🔥 实战踩坑：U5（CA-IS3742HW）副边桥锡导致 U2 隔离 DC-DC 发热（2026-08）

> 用户真实排查记录，整理出来避免你重蹈覆辙。本板当时 U1 已拆下（损坏待换），其余 IC（U2/U5/U3/U4）均已焊接，上电发现 U2 摸起来发烫。

**现象（一步步排查记录）：**
1. U2（B0505S-1WR3）上电后**明显发热**——文档 §关卡 A 异常处理表把"模块发热"列为危险信号，要求立刻断电。
2. 先排除 C26：蜂鸣测 C26 两焊脚 ↔ U2 的 3/4 脚均导通（在位、接对），且 C26 两焊脚 ↔ USB 侧 GND / 系统 3V3 均**不响** → C26 正常，不是发热原因。
3. 确认 U2 方向：1 脚圆点对齐 PCB 丝印（1=-Vin、2=+Vin、3=-Vout、4=+Vout）→ 方向正确。
4. 蜂鸣查 U5 副边：第 9 脚 ↔ 第 15 脚**响**（同为 GNDB，符合预期）；但 `VDDB(16) ↔ GNDB(9/15)` **响** → 说明 U5 隔离侧 `VDDB ↔ GNDB` 直接短路。
5. 结论：U5 把 U2 的隔离 5V 输出（ISO_5V / +Vout）和隔离地（ISO_GND / -Vout）短接在一起，U2 一上电输出就被短路 → 过载发热。
6. 重焊 U5 后复测 `VDDB(16) ↔ GNDB(9/15)` **不响**，短路消失；U2 不再被拉短路。

**根因判断：**
- SOIC-16 密脚，U5 第 15 脚（GNDB）与第 16 脚（VDDB）**相邻**，手焊时锡偏多 → 桥锡，把隔离侧电源和地短接。
- 这是典型"手焊密脚 IC 桥锡"问题，不是芯片本身坏（重焊即好），也不是 U2 坏（U2 发热是被动被短路拉垮）。

**排查顺序（U2 发热时按此走）：**
1. 断电，蜂鸣查 C26 是否在位、有没误接系统地 → 排除滤波漏焊。
2. 确认 U2 方向（1 脚对齐）→ 排除方向反。
3. 蜂鸣 `USB 侧 GND ↔ U2 副边 -Vout(3)` → 应不响（隔离成立铁证；响 = 隔离侧意外接地）。
4. 蜂鸣查隔离侧 IC 电源对地：`U5 VDDB(16)↔GNDB(9/15)`、`U3/U4 VCC(3)↔GND(2)` → 全应不响；任一项响 = 那颗 IC 把 U2 拉短路。
5. 蜂鸣查 `USB 侧 GND ↔ U5/U3/U4 的隔离地` → 全应不响（响 = 隔离屏障被打穿到系统侧）。
6. 以上全正常仍热 → U2 可能已在首次上电被烫坏，换颗新 B0505S（立创 C7465178）。

**换新前必做（避免反复发热）：**
- [ ] U2 发热先**断电**，别连续通电烤。
- [ ] 用显微镜查 U5/U3/U4 相邻脚有没有桥锡（尤其 U5 的 15/16 脚），有桥用焊油 + 吸锡带修。
- [ ] 修/重焊后断电蜂鸣确认隔离侧电源对地不短路、隔离地不碰系统 GND，再上电。
- [ ] 上电点测 `U2 +Vout(4) ↔ -Vout(3) = 5V±0.25V` 且**不烫**，才算关卡 A 通过。

> ⚠️ 测量全程只用万用表蜂鸣档，板子断电悬浮，**严禁把板子 GND 接到插线板/市电大地**（会破坏隔离、引入触电风险）。

### 5.3 烧录固件
> 详细烧录流程见 [`firmware/README.md`](../firmware/README.md) 与 HPMicro 官方文档。

1. **HPM5321(QFN48) 的 USB 引脚在 LQFP100 才有**，**所以走串口烧录**（详见 [`docs/glossary.md` ISP](glossary.md)）
2. 下载 [HPMicro Manufacturing Tool](http://www.hpmicro.com/)（HPMicro 官网资源页），准备 USB-TTL 串口模块（3.3V，别接 5V，会烧）
3. 接线：USB-TTL 的 `TX → H1.RX`, `RX → H1.TX`, `GND → H1.GND`
4. 按住板子 **SW1（BOOT 按键）** → 接 USB 上电 → 出现 COM 口后松开
5. Manufacturing Tool 检测到 COM 口 → 选 [`firmware/FDFW_20260201.bin`](../firmware/FDFW_20260201.bin) → 烧录
6. **烧录成功** → 重启 → 插电脑 USB，**设备管理器出现 PCAN-USB** 设备（设备 ID `0x0BFD/0x0001` 或类似 PEAK 仿冒标识）

### 5.4 通信测试
- Windows：装 [PEAK PCAN-View](https://www.peak-system.com/PCAN-View.5.0_LANG=EN.html)（或 PCAN-Basic）
- Linux：`ip link` 应该看到 `can0` / `can1`（如果 socketcan 已识别）
- 发送一帧：`TX: 123#DEADBEEFCAFEBABE`（CAN-FD 标准帧）
- 接收：自身回环（把 CANH / CANL 短接 or 用 DB9 回环头）能收到回显，**说明 CAN 收发器 + 隔离器 + MCU 都通了**

## 6. 故障排查表

| 症状 | 可能原因 | 排查方法 |
| --- | --- | --- |
| 插 USB 没反应（设备管理器无 PCAN） | (1) MCU 没起振；(2) QFN 桥锡；(3) 烧录没成功 | (1) 测晶振电压 1.6V；(2) 显微镜查 QFN 每脚；(3) 重烧录 |
| 3.3V 偏低（2.5V~3.0V） | 退耦不足 / 某芯片短路 | 摸芯片温度、断开 LDO 输出测空载电压 |
| 3.3V 为 0 | LDO 方向焊错 / 输入 5V 没到 | 重测输入、查 LDO 1 脚 |
| USB 枚举但看不到 PCAN | USB ESD 桥锡 / D+/D- 桥锡 | 显微镜查 USB1 |
| CAN 发不出 | (1) 隔离器方向；(2) 收发器 1 脚；(3) CC 下拉没焊 | 量隔离器输出给收发器的 CAN-TX |
| CAN 错误帧（Error Frame 满屏） | (1) 终端电阻没接；(2) 收发器 TX/RX 接反 | 检查 SW2 拨到 ON、用万用表量 CANH-CANL 应 ≈ 60Ω |
| MCU 烫手 | QFN 内部短路 / 桥锡严重 | **立刻断电**，显微镜 + 吸锡带 |
| 隔离两端地量到导通 | U2 插件方向焊反 / 桥锡 | 检查 U2 / U5 周围 |
| 烧录失败「No Response」 | 串口线接反 / BOOT 没进 / 串口不是 3.3V | 查 RX/TX 是否交叉、查 BOOT 拨位 |
