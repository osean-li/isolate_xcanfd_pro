0. 这块板子是干嘛的

你手上（或屏幕上）打开的，是一个“USB 转 CAN FD”的适配器。通俗地说：

  • 电脑只有 USB 口，但汽车、工业设备用的是 CAN / CAN FD 总线（一种汽车和工控里非常常见的“车内/设备间通信网线”）。
  • 这块小板子夹在中间，把电脑发来的 USB 数据，“翻译”成 CAN 总线上的信号，让电脑能收发汽车/设备里的报文。反过来也一样。
  • 它兼容 PCAN-FD PRO（一个著名的德国品牌产品），也就是说电脑上装对应的驱动和软件（PCAN-View / TSMaster 等）就能直接用它，不用自己写底层。
  • 它支持 CAN FD（CAN 的升级版，数据段最高 8Mbps），并且对 CAN 侧做了 1500V 电气隔离——这是它最核心的设计亮点，后面会专门讲。
小白先记住一句话：任何一块电路板，本质上都在做三件事——取电（电源）、处理信息（芯片）、连接外面的世界（接口）。看完这份文档，你会发现本板 every 元件都能归到这三类里。

1. 硬件世界的基本语言

在看原理图之前，先建立几个最基础的概念。这些概念每一个，后面都会用本板上的真实元件来举例。

1.1 电压、电流、电阻（欧姆定律）

最经典的类比：把电看成水。

  • 电压（Voltage，单位 V 伏特） = 水压。水压越高，水越有“冲劲”。电池/电源提供电压。
  • 电流（Current，单位 A 安培） = 水流量。单位时间内流过多少电荷。
  • 电阻（Resistance，单位 Ω 欧姆） = 水管粗细/弯头。阻碍电流。

三者的关系叫 欧姆定律：电压 = 电流 × 电阻，即 V = I × R。

图 1-1：用水压/水流理解电压/电流/电阻
本板实例：USB 口进来是 5V（VBUS），经过 LDO1(ME6211) 降到 3.3V 给主控芯片供电。如果某处电流太大、电阻太小，就会“短路”烧东西——所以板上到处是电阻和保险式的保护元件。

1.2 电路、GND 与“回路”

电流必须有来有回才能流动，就像水要从管子出去还得流回来。电的“回来”的那条路，通常叫 GND（地 / Ground）。你可以把 GND 想象成“公共下水道/海平面”——所有电压的“0 基准”都参考它。

  • 板上你看到很多 GND 符号，它们都连在一起，是同一个“0 伏参考点”。
  • 本板还有一个 ISO_GND——“隔离地”。它和 GND 不连通，是实现隔离的关键（见模块 4.3）。

1.3 什么是“网络（Net）”

原理图里，凡是被一根线（或同一个网络标号）连起来的所有引脚，在物理上就是连在一起的同一根导线，这在 EDA 里叫一个 网络（Net）。

小白重点：原理图上的“线”不是真的线，而是“这些点属于同一个网络”的声明。比如所有标着 3V3 的地方，最后在 PCB 上都会用铜皮连起来，给芯片供 3.3V。网络名相同 = 电气连通。

本板核心网络（从工程里读到的真实网络名）：

5V（USB 进来系统 5V）   3V3（LDO 出来的 3.3V）   ISO_5V（隔离侧的 5V）   GND（系统地）   ISO_GND（隔离地）
还有 MCU 内部电源域：VIO VANA VPMC VREFH VSOC VDD_PMCCAP VDD_OTPCAP DCDC_LP —— 这些是 HPM5321 芯片内部不同模块的供电脚。

1.4 数字信号：0 和 1 怎么传

芯片之间不传“模拟水”，而传高/低电平：比如 3.3V 代表“1”，0V（GND）代表“0”。一串 0/1 就是数据。CAN 总线更特殊，它用两根线之间的电压差来表示 0/1（差分信号），抗干扰强——这正是 CAN 能在汽车这种“电噪声很大”的环境里可靠工作的原因。

2. 电子元器件 ABC

下面逐个认识本板用到的元件类型。每一类都配了本板上的真实型号。

2.1 电阻 R / 电容 C / 电感 L

电阻 Resistor（位号 R）

阻碍电流。阻值单位 Ω（欧姆）、kΩ（千欧）。本板有：

  • R8 R9 = 120Ω：CAN 总线终端电阻
  • R10 R11 = 5.1kΩ：USB-C 的 CC 配置电阻
  • R1-R4 = 5.1kΩ：MCU 配置/上下拉
  • R5-R7 = 10kΩ：上拉电阻

封装从 R0402(1.0×0.5mm) 到 R0805(2.0×1.25mm) 不等，越小越省空间。

电容 Capacitor（位号 C）

“储电小水箱”，用来滤波、退耦、稳压。本板有约 30 颗：

  • 100nF(C0603) ×14：退耦电容，紧贴每个电源脚，滤高频噪声
  • 10uF / 4.7uF / 22uF / 1uF：电源滤波
  • 22pF(C1 C2)：晶振负载电容

“退耦”= 在芯片电源脚旁放一颗小电容，像给芯片配个“小水库”，电压一抖就由它补上，不让芯片重启/出错。

电感 Inductor（位号 L）

“阻交流、通直流”的线圈。L1 = 4.7uH 是 HPM5321 内部 DCDC 的功率电感，配合电容把电压降到内核所需的低压大电流。电感值和电流/饱和电流是关键参数。

2.2 二极管：LED / TVS / ESD（位号 D）

二极管只让电流单向通过，像“单向阀”。本板用了三种二极管：

  • LED（发光二极管）：D1 D2（黄绿色，直插）。正向导通约 2V，串电阻限流后发光，作状态指示。
  • TVS（瞬态抑制二极管）：D3（SOD-123，5V）。平时开路，一旦电压被浪涌（雷击/插拔火花）冲高，它立刻“击穿”把高压泄放到地，保护后级。参数：Vrwm 5V、钳位 9.2V、Ipp 21.7A。
  • ESD（静电保护二极管）：D4 D5（SOT-23-3）、D6（SOT-23-6，5V）。专门防人体静电（几千伏瞬间放电）打坏敏感引脚，常用于 USB、CAN 对外接口。

2.3 晶振 Crystal（位号 X / Y）

X1 = 24MHz 晶振（负载 12pF，±10ppm）。它像一个极精准的“节拍器”，给 MCU 提供主时钟。没有它，芯片就不知道“一秒有多长”，通信全乱。旁边的 C1 C2 = 22pF 是它的“负载电容”，帮助起振。

2.4 连接器 & 开关（位号 CN / USB / H / SW）

  • USB 母座：USB1（Type-C，16 脚，卧贴）。对外的 USB 接口，同时取电+通信。
  • 接线端子：CN1 CN2（3.81mm 间距，3P，绿色弯针）。把 CAN 的 CANH / CANL / GND 接到外部总线，免焊接、可插拔。
  • 排针：H1（1×8，2.54mm）。调试/烧录串口，接“串口转 USB 工具”给芯片刷固件。
  • 开关：SW1（4 位拨码，SMD）用于功能/地址配置；SW2（2 位琴键）用于切换 CAN 终端电阻 120Ω 是否接入。

2.5 芯片：MCU / LDO / 隔离器 / 收发器（位号 U）

MCU 微控制器（大脑）

U1 = HPM5321（QFN-48，RISC-V 架构，主频高、带 USB 高速和 2 路 CAN-FD）。它跑固件，把 USB 数据包转成 CAN 帧。相当于整块板的“CPU”。

LDO 线性稳压器（降压）

LDO1 = ME6211（SOT-23-5）。把 5V 稳稳降到 3.3V，最大 500mA。原理像“可调水龙头”，输入高输出低，多余的能量变成热量散掉。简单、干净、便宜。

隔离 DC-DC（隔离电源）

U2 = B0505S-1WR3。输入 5V、输出隔离的 5V（200mA），两侧不共地，隔离电压 1500V。给“隔离侧”单独供电，是实现 CAN 隔离的核心之一。

数字隔离器（信号隔离）

U5 = CA-IS3742HW（SOIC-16，4 通道）。像“用光/电场隔开的传送带”，把 MCU 侧的 TX/RX 数字信号“隔空”传到隔离侧，两侧地不连。配合 U2 实现完整 1500V 隔离。

CAN-FD 收发器（电平翻译）

U3 U4 = SIT1042（SOP-8）×2。MCU 的 TX/RX 是普通逻辑电平，CAN 总线是“差分”的。收发器负责两边互译：MCU 说“1”，它在 CANH/CANL 上制造一个电压差；反过来也行。每路 CAN 通道一颗。

3. 看懂原理图

3.1 原理图符号 vs PCB 封装

同一个元件在三个地方长不一样：

  • 原理图符号（Symbol）：画逻辑连接用的“简图”，比如电阻画成一个小矩形。重在“连哪几个脚”。
  • PCB 封装（Footprint）：元件在板子上的真实“焊盘形状”，比如 C0603 表示 0603 规格（1.6×0.8mm）的两个焊盘。重在“怎么焊”。
  • 实物：你手上焊上去的那颗料。
小白记法：Symbol 是“身份证照”（用来连线），Footprint 是“座位”（用来焊接）。本板里 R0603 这种写的是封装名，告诉你它占多大地方。

现在把整块板像拆乐高一样拆开。下面这张框图是灵魂，建议反复看：

图 4-1：本板功能框图——红色虚线是 1500V 隔离屏障，屏障右侧（CAN 侧）与左侧（电脑/MCU 侧）电气上完全隔开

4.1 USB 接口与供电（USB 页 + CAN/POWER 页）

  • USB1：插上电脑后，电脑通过 VBUS 给板子供 5V（本板网络 5V / VBUS_5V）。同时 USB 数据线（D+/D- 或本板的 USB 高速差分对）与电脑通信。
  • R10 R11 = 5.1kΩ：Type-C 的 CC1/CC2 脚下拉电阻。它告诉电脑“我是一个需要供电的设备（sink）”，并参与供电能力协商。没有它，电脑可能不给你供电。
  • D6：ESD 保护，防止插拔 USB 时的静电打坏芯片。
USB 高速差分对：HPM5321 的 USB 是“高速（480Mbps）”模式，数据走一对线 USBHS_DP / USBHS_DM（以及可能的第二对 _S）。这对线是“差分对”，在 PCB 上必须按 90Ω 差分阻抗走线（见模块 6）。

4.2 电源系统（CAN/POWER 页）

进来的 5V 一分为二：

路径元件作用
非隔离侧（给 MCU）LDO1 ME62115V → 3.3V（3V3），给 HPM5321 的 IO/数字部分供电，500mA 够用
隔离侧（给 CAN 侧）U2 B0505S5V → 隔离 5V（ISO_5V），两侧不共地，实现隔离供电

滤波/退耦电容：C22–C29 等围绕稳压器做输入/输出滤波（1uF、10uF、100nF 组合），让电压平稳、不被干扰。这些“小水箱”是电源质量的保证。

4.3 隔离屏障（本板最值钱的设计）

为什么需要隔离？汽车/工业 CAN 总线可能带几十伏甚至上千伏的共模干扰、地电位差、浪涌。如果板和电脑直接共地，这些高压会顺着 USB 线窜进你昂贵的电脑，烧接口甚至伤人。隔离让“信号能过去，电过不去”。

两件套实现隔离

  • U2 B0505S：隔离电源（能量隔离）
  • U5 CA-IS3742HW：隔离信号（4 通道数字隔离器，把 TX/RX 隔空传过去）

两者配合，CAN 侧（ISO_5V/ISO_GND）与电脑侧（5V/GND）在电气上彻底分开，额定隔离 1500V。

PCB 上怎么体现

在板子上，隔离器两侧之间会留出一条“隔离带”——这条缝里不放铜、不走线、加大间距，满足爬电距离（creepage）和电气间隙（clearance）要求，才能保证 1500V 不击穿。这就是图 4-1 红虚线的物理意义。

4.4 CAN 收发（CAN/POWER 页）

  • U3 U4 = SIT1042：两路 CAN-FD 收发器，把 MCU 的逻辑 TX/RX 变成 CAN 总线上的差分信号 CANH/CANL。
  • CN1 CN2：3.81mm 绿色接线端子，引出 CANH / CANL / GND 接外部总线（每路一个通道）。
  • R8 R9 = 120Ω：CAN 总线终端电阻。CAN 是 120Ω characteristic impedance 的总线，两端各放 120Ω 吸收信号反射。本板把它内置了。
  • SW2：2 位琴键开关，切换 120Ω 是否接入。标准做法：总线两端各有一个终端，中间节点不加。所以板子做开关让你按实际接线决定。
  • D3(TVS) D4 D5(ESD)：保护 CAN 引脚免受浪涌和静电。

4.5 主控与配置（CORE 页）

  • U1 HPM5321：RISC-V 主控，运行固件做 USB↔CAN 协议转换。它内部有 USB 高速 PHY 和 2 路 MCAN 控制器。
  • X1 24MHz + C1 C2 22pF：主时钟。
  • L1 4.7uH + C20 C21 22uF：内部 DCDC（DCDC_LP 网络）给内核供电。
  • C3–C19 等 100nF ×14：几乎每个电源脚旁一颗退耦电容。
  • R1–R4 = 5.1kΩ、R5–R7 = 10kΩ：启动配置/上下拉电阻（设置 MCU 上电从哪里启动、引脚默认电平）。
  • SW1：4 位拨码开关，用于功能/通道配置。
  • H1：1×8 排针，接串口转 USB 工具，用于烧录固件和调试。
  • D1 D2：状态 LED（比如指示通道活动）。

5. PCB 设计入门

5.1 什么是 PCB

PCB（Printed Circuit Board，印刷电路板）就是那块绿色的板子。原理图告诉你“谁和谁连”，PCB 把这种连接变成板子上的铜皮走线，并把元件焊接固定。

小白记法：原理图 = 电路“接线图”（逻辑）；PCB = 板子“实物布局图”（物理）。EDA 软件会根据原理图的“网络”自动在 PCB 里连接对应焊盘。

5.2 层、焊盘、过孔

  • 层（Layer）：PCB 不只是“一层”。像本板是 4 层板——有 4 张铜皮叠在一起，中间用绝缘的 FR-4 隔开。
  • 焊盘（Pad）：元件引脚要焊上去的“铜小块”。封装（Footprint）本质就是焊盘的集合。
  • 过孔（Via）：打穿板子的金属小孔，用来把信号从一层“换”到另一层，像立交桥。
  • 丝印（Silkscreen）：板子表面白色的字（R1、U1 等），方便焊接和维修。
  • 阻焊（Solder Mask）：绿色（或别的颜色）的漆，盖住不需要焊接的铜，只在焊盘开窗，防止短路和氧化。

5.3 为什么用 4 层板而不是 2 层

2 层板只有顶/底两层铜，所有走线和电源/地都挤在两面，密集时很难布通，且地不完整。4 层板通常把中间两层专门做成 完整的地平面（GND Plane） 和 电源平面（PWR Plane）：

图 5-1：本板 4 层板实测剖面——绿色为信号铜层、蓝色为 GND 平面、红色为 Power 平面、黄色为 FR-4 绝缘介质，灰色为阻焊层。只数铜层，本板 4 个 = 4 层板
  • 完整的地平面 = 信号有稳定“回流路径”，抗干扰强、EMC 好。
  • 电源平面 = 供电均匀、阻抗低。
  • 本板元件多（约 60 个 PCB 封装）、有高速 USB 和隔离要求，用 4 层是合理选择。

5.3.1 实操：在嘉立创 EDA 里怎么看层数（小白必会）

看完上面的理论，你肯定想在软件里自己确认一下"到底是不是 4 层"。最准确的方法就是看右侧的「层管理」面板——记住一句话：只看「铜箔」分组，不看「其他」分组。

看「铜箔」分组直接数（最推荐）

在 PCB 编辑界面，右侧「层管理」面板会把所有层分成 「铜箔」 和 「其他」 两组：

  • 铜箔组：列出所有含铜的层。本板显示 1 顶层 15 内层1 16 内层2 2 底层 → 共 4 个铜层 = 4 层板。
  • 其他组：列出丝印层、阻焊层、锡膏层、装配层、板框层等（本板显示为「12 多层」）。这些都不含金属铜，不算层数。

所以你不用自己费劲分辨哪些是装饰层——软件已经用「铜箔 / 其他」分好类了，你只数「铜箔」里有几项就完事。

另外 3 种辅助看法：
  1. 底部层标签栏：画布正下方有一排可点的层标签，能看到「顶层 · 内层1 · 内层2 · 底层」，有几个铜层标签就是几层，比数菜单还快。
  2. 顶部菜单「设计 → 层管理 / 叠层管理」：弹出完整的叠层剖面（L1 / L2 / L3 / L4… 加每层厚度、材质），这是最"权威"的查看方式。
  3. 板子信息 / 属性面板：选中板框（Board Outline），在属性里翻到「层数」字段，会直接写 4。
一句话口诀：嘉立创 EDA「层管理」面板的「铜箔」分组下有几项，就是几层板。本板 = 4 项 = 4 层板。带丝印、阻焊、锡膏、装配字样的层都不算。

5.4 隔离与布局（本板特色）

因为要 1500V 隔离，PCB 布局上把板子分成两个区域：

  • 非隔离区：USB、MCU、LDO、电脑侧地（GND）。
  • 隔离区：隔离电源 U2、隔离器 U5、收发器 U3/U4、端子 CN1/CN2、隔离地（ISO_GND）。

两区之间画一条隔离槽/禁布带，物理上保证爬电距离。元件摆放也遵循“信号从 MCU → 隔离器 → 收发器 → 端子”的顺序，一路单向走，避免交叉耦合。

安全提醒：隔离的可靠性 90% 取决于 PCB 上的间距和隔离带，不是只看芯片标称 1500V。layout 时这条缝不能随便被丝印、测试点、走线跨越。

6. PCB 设计进阶实战

6.1 叠层与阻抗控制

典型 4 层板叠层（从上到下）：

图 6-1：典型 4 层板叠层示意（本板采用类似结构，隔离电源在 L3 上与系统地分区隔离）

阻抗控制是什么？高速信号（如 USB 差分对）对“线看起来像多少欧姆”很敏感。如果阻抗不匹配，信号会在端点反射、变形，导致通信错误。USB 高速差分对要求 90Ω 差分阻抗。

本板注意点：工程记忆里提到，本板下单时选了“阻抗管控：无要求”——但板上明明有 USB 高速差分对（90Ω）。建议：若重新打板，应在嘉立创下单时勾选“阻抗管控”并备注 USB 差分对 90Ω，或按厂家的 90Ω 叠层参数（线宽/线距/介质厚）来走线，否则高速通信可能不稳定。

6.2 差分对走线

USB 的 DP/DM 是一对“差分线”：信号靠两根线的电压差表示。走线规则：

  • 等长：两根线长度尽量一致（长度差通常要求 < 5–15mil），否则差分信号“歪了”。
  • 等距/紧耦合：两根线平行、间距固定，保持 90Ω 差分阻抗。
  • 少换层、远离干扰：尽量不穿过隔离带，远离电源和时钟。
图 6-2：USB 差分对——两根线等长、等距，整体呈现 90Ω 差分阻抗

6.3 DRC 与可制造性（DFM）

DRC（Design Rule Check，设计规则检查）：EDA 软件按你设定的规则（最小线宽、最小间距、过孔大小、短路/开路）自动扫描 PCB，报错让你改。打板前必跑。

嘉立创（JLCPCB）常见工艺下限（参考，以官网为准）：

参数常用下限说明

8. 动手：焊接与调试（小白实操）

板子是贴片（SMD）设计，元件小、引脚密，对刚入门的朋友确实有点挑战。但拆开看，它遵循一条铁律：先焊“地基”，确认没问题了，再焊“大脑”，最后才通电烧录。 这样万一焊错，损失最小、最好查。

核心原则：被动元件 + 连接器 → 电源系统（先不上主控）→ 主控 QFN → 隔离/收发 → 上电 → 烧录。每焊完一段，就用万用表验一段，确认不短路、电压对，再往下走。

8.0 焊前准备（先做这些再下烙铁）

工具清单（三类分开）：

  • 焊接：恒温电烙铁（60W+、尖头/刀头）、0.5–0.8mm 含松香芯焊锡丝、助焊膏、热风拆焊台（QFN 强烈推荐）、尖头防静电镊子、放大镜/显微镜、吸锡带、酒精棉签（洗板）、静电手环。
  • 调试：万用表（蜂鸣/二极管/电压/电阻档齐全）、带限流的直流稳压电源（第一次上电必用，设 100mA 限流防短路烧板）。
  • 烧录：USB 转串口模块（CH340/CP2102，3.3V 电平）、HPMicro_Manufacturing_Tool。详见第 9 节。

8.7 阶段 7｜★ QFN-48 主控（全板最难点）

焊：U1 HPM5321（3D 图中央深灰色、没有外露引脚的小方块，底部有散热焊盘）。引脚在芯片底面，肉眼看不到，最易虚焊/桥接。两种焊法二选一：

  • A. 热风枪回流（推荐新手）：① 焊盘薄涂一层助焊膏；② 芯片按 1 脚圆点对位；③ 热风枪 320–340°C、小风量，芯片上方 3–5cm 匀速画圈加热；④ 锡熔后表面张力会把芯片“吸”回正位；⑤ 自然冷却，勿动。
  • B. 烙铁拖焊：① 先对角点焊固定；② 涂大量助焊剂；③ 烙铁挂锡，从一端缓慢拖过所有引脚；④ 多余锡用吸锡带清掉。
★ 焊完必做：① 显微镜/放大镜查四边无桥接（相邻脚不可粘连）；② 底部散热焊盘必须接地（烙铁尖从侧面伸进缝隙补锡）；③ 蜂鸣档测所有相邻脚不响，且 3.3V 脚与 GND 响（去耦正常）。

8.8 阶段 8｜通电验证 + 烧录联调

  1. 再次全板测电源：限流 100mA 上电，电流应 30–80mA。任何 >100mA 立即断电查短路。
  2. USB 转串口模块接线（见第 9 节）：模块 TX→H1 的 DBG_RX、RX→DBG_TX、GND→GND，模块拨 3.3V（5V 会烧主控）。
  3. 进入 ISP 模式：按住 SW1 拨到 BOOT=1（或按住 BOOT 按钮），不松手→USB 上电→HPMicro_Manufacturing_Tool 识别到设备→松手。
  4. 烧录：选固件 FDFW_xxxxxx.bin → 烧写 → 复位。
  5. 验收：LED D1/D2 按节拍闪；电脑设备管理器多出 USB 设备；CAN 上位机能收发帧。

11. 术语表 & 延伸阅读

速查术语

  • PCB：印刷电路板，板子的实物。
  • 原理图（Schematic）：表示“谁和谁电气连通”的逻辑图。
  • 位号（Designator）：元件编号，如 R1、U1。
  • 封装（Footprint）：元件在 PCB 上的焊盘形状。
  • 网络（Net）：原理图里被连在一起的所有点，物理上同一根线。
  • GND：地，电压的 0 基准/回流路径。
  • LDO：低压差线性稳压器，降压芯片。
  • DC-DC：开关电源，高效率升降压。
  • 隔离（Isolation）：让信号过、电不过，防高压串入。
  • CAN / CAN FD：汽车/工控通信总线；FD 是加速版（数据段可达 8Mbps）。
  • 差分信号：用两根线电压差表示 0/1，抗干扰强。
  • 阻抗（Impedance）：高频下“线看起来像多少欧姆”，USB 差分对要求 90Ω。
  • 差分对：一对等长等距走线（如 USB DP/DM）。
  • 过孔（Via）：打通各层、换层的金属小孔。
  • DRC：设计规则检查，打板前必跑。
  • 爬电/间隙：隔离所需的最小表面距离/空间距离。
