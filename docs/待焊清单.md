## 9. 组 8：主控 MCU U1（HPM5321 QFN-48，最难最贵，最后焊）

> **全板最贵最难的件，放在所有其它件焊完、关卡 A 已通过之后最后焊。** 焊完做 🔑关卡 B 整板上电通检（见 §10）。

- [ ] **U1** HPM5321IEG1（QFN-48）— [照片](元器件照片/HPM5321IEG1.jpg)
  - **48 脚全在肚子底下 + 底部散热焊盘**，烙铁伸不进去，**必须热风枪 + 锡膏**。全板最难，**建议先拿废板练一次手感**。

  **方法 A（热风枪 + 锡膏，推荐）**：
  1. PCB 焊盘涂**薄**锡膏（钢网最佳；没有用刮刀/牙签薄涂，堆厚必桥）。
  2. 镊子摆上，**注意第 1 脚**（点标记/切口/丝印），对齐 PCB 1 脚。
  3. 热风枪 **350°C** 中档风，画小圆加热整颗。
  4. 看到锡膏整体反光熔化，芯片自动"归位"（自对中效应）。
  5. **加热 ≤ 90 秒**，否则基板鼓包。冷却后显微镜查四角、吸锡带修桥。

  **方法 B（烙铁 + 助焊膏，慎用）**：涂助焊膏→摆正对 1 脚→刀口烙铁+大量锡拖焊 4 边→吸锡带修桥→**底部散热焊盘从背面空窗单独补锡**（新手最易漏）。

**焊完检查（🔑 关卡 B 之前）**：
- [ ] 显微镜看芯片四周无缝隙、1 脚对齐、四角焊点均匀
- [ ] 二极管档测 48 脚相邻脚 → 不短路（应有 PN 结压降，不是 0Ω）
- [ ] 蜂鸣测所有 VDD 脚对地 → 不响

---

## 10. 全部焊完 → 上电通检 & 烧录（入口）

补焊全部完成后，进入完整自检（详细见 [`soldering-guide.md` §5](soldering-guide.md)）：

1. **焊完 MCU 后完整自检**：所有 VDD↔GND 不短路；HPM5321 每相邻脚不短路；插 USB 测 3V3 仍 3.30V 不跌；晶振引脚两端约 1.6V（启振后）。
2. **烧录固件**：HPM5321(QFN48) 的 USB 引脚只在 LQFP100 才有 → **走串口烧录**。USB-TTL（3.3V！）接 H1：`TX→H1.RX`、`RX→H1.TX`、`GND→H1.GND`；按住 BOOT 键接 USB 松开 → HPMicro Manufacturing Tool 选 `firmware/FDFW_20260201.bin` 烧录。
3. **通信测试**：Windows 用 PCAN-View；Linux `ip link` 看 `can0/can1`；发一帧自身回环能收到 = CAN 收发器+隔离器+MCU 全通。

> 每修一次故障，回 [`docs/my-build-log.md`](my-build-log.md) 补一段真实 debug 记录 —— 这是你简历/作品集的"原创实物调试"素材。
