# 烧录与接线速查卡（HPM5321 隔离 USB‑CAN FD）

> 适用：已焊完整板，准备**首次上电 → 串口烧录 → 接 CAN 线束**的人。
> 数据来源：本仓库 `hardware/*.epro2` 网络表（H1 / SW1 / CN1 / CN2 真实引脚）+ `firmware/README.md` + `docs/soldering-guide.md`。
> ⚠️ 凡涉及"哪一位 BOOT"都以**网络表 + 万用表实测**为准，不要只凭记忆。

---

## 0. 首次上电前必做的安全检查（别跳过，能救一块 MCU）

你刚焊完，第一次通电最容易翻车。先不通电做三件事：

| 检查 | 方法 | 期望 |
| --- | --- | --- |
| 3V3 对地 | 黑笔 GND，红笔量 LDO1 输出 | **不响**（响 = 电源对地短路，先别上电） |
| 5V 对地 | 黑笔 GND，红笔量 USB1 的 VBUS | 不响 |
| **隔离成立** | 黑笔 USB 侧 GND，红笔 U2 副边 `VOUT-`（CAN 侧地） | **不响 / OL**（响 = 隔离没隔开，先查 U2 方向） |
| QFN 相邻脚 | 二极管档挨个量 U1 相邻引脚 | 有 PN 结压降，**不是 0Ω** |

全部 OK 再插 USB‑C。插上后量 3V3 应为 3.30V 且不跌。

---

## 1. 烧录需要的材料

- 电脑一台（Windows，跑 HPMicro Manufacturing Tool）
- **USB‑TTL 串口模块** 1 个（CH340 / CP2102 / FT232 都行），**务必拨到 3.3V 逻辑电平，千万别用 5V**
- 杜邦线 3 根（TX / RX / GND）
- 仓库里的 `firmware/FDFW_20260201.bin`
- 仓库 `tools/` 下的 `HPMicro_Manufacturing_Tool_v0.6.0.zip`（解压即用）

> HPM5321 是 **QFN48 封装，没有 USB‑Boot 引脚**，只能用 **UART0 串口 ISP** 烧录。USB‑C 只负责供电 + 烧完后的正常通信。

---

## 2. H1 调试/烧录排针引脚定义（1×8，顶部）

从**丝印文字面**看，引脚 1→8 排列如下（左侧为 1 脚，右侧为 8 脚）：

```
 1       2       3       4       5        6       7      8
[TDO]  [TDI]   [TCK]   [TMS]   [RX]    [TX]    [GND]  [GND]
 DBG_TDO DBG_TDI DBG_TCK DBG_TMS DBG_RX  DBG_TX   GND    GND
```

| H1 脚 | 网络名 | 说明 | 烧录用？ |
| --- | --- | --- | --- |
| 1 | DBG_TDO | JTAG/SWD 数据输出 | 不用 |
| 2 | DBG_TDI | JTAG/SWD 数据输入 | 不用 |
| 3 | DBG_TCK | JTAG/SWD 时钟 | 不用 |
| 4 | DBG_TMS | JTAG/SWD 模式选择 / SWDIO | 不用 |
| **5** | **DBG_RX** | **MCU 串口接收（UART0 RX）** | ✅ 接 TTL 的 TX |
| **6** | **DBG_TX** | **MCU 串口发送（UART0 TX）** | ✅ 接 TTL 的 RX |
| 7 | GND | 地 | ✅ 接 TTL 的 GND |
| 8 | GND | 地 | （备用 GND） |

> 前 4 脚是 SWD/JTAG 调试口（以后想用 JLink/OpenOCD 调试固件才用），**烧录只用 5/6/7 这三脚**。
> H1 上**没有 3.3V 脚**，板子靠 USB‑C 供电，USB‑TTL 只提供信号线，不要从 TTL 给板子供 3.3V。

---

## 3. USB‑TTL ↔ H1 接线（交叉接）

| USB‑TTL 模块 | → | H1 排针 |
| --- | --- | --- |
| **TX** | → | **pin 5（DBG_RX）** |
| **RX** | → | **pin 6（DBG_TX）** |
| **GND** | → | **pin 7（GND）** |
| 3.3V / 5V | ✗ | **不接**（模块自身拨到 3.3V 逻辑电平即可） |

口诀：**TX 对 RX、RX 对 TX、交叉、共地、电平选 3.3V**。

---

## 4. SW1 按键：进 ISP 模式（BOOT 按钮）

SW1 是**轻触按键**（TS-KG89S-AT25F），网络表显示：**pin2 = 3V3，pin3 = BOOT0**（其余两脚悬空）。**按下时两脚导通**，把 BOOT0 拉到 3V3。
进 ISP 的本质是：**把 BOOT0 拉到 3V3（高电平）**，芯片上电时就会进 UART0 烧录模式，而不是从 Flash 启动。

**怎么确认 SW1 的 BOOT 功能（可靠做法，不靠记）：**
- 板上 SW1 旁边丝印通常标了 `BOOT`，**按住按键**即可。
- 丝印看不清就用**万用表蜂鸣档**确认（断电操作）：
  1. 先找到 SW1 上接 3V3 的脚（pin2）和接 BOOT0 的脚（pin3）——它们分别在按键两端。
  2. 蜂鸣档量"3V3 侧焊盘 ↔ BOOT0 侧焊盘"：**按下导通，松开断开**，这就是 BOOT 按键。

> 正常使用时（烧完固件后）**松开 SW1**（BOOT0 下拉接地），上电即从 Flash 启动，USB‑C 才会被识别成 PCAN 设备。

## 5. 烧录步骤（HPMicro Manufacturing Tool）

1. 解压 `tools/HPMicro_Manufacturing_Tool_v0.6.0.zip`，运行 GUI。
2. **按住 SW1（BOOT 按键）**，再接 USB‑C 给板子上电（BOOT0 在复位瞬间被采样为高），出现 COM 口后**松开**。
3. USB‑TTL 插电脑，设备管理器里出现一个**新 COM 口**（记下端口号，如 COM5）。
4. 工具里选该 COM 口 → **载入 `firmware/FDFW_20260201.bin`** → 点连接/烧写。
5. 进度条走完提示成功 → **松开 SW1** → 断开 USB‑C 再重插。
6. 电脑设备管理器出现 **PCAN‑USB / PEAK** 类设备（设备 ID 类似 `0x0BFD/0x0001`），说明固件已正常启动。

> 烧录失败提示 `No Response`：90% 是 TX/RX 没交叉、或 BOOT 没进、或串口模块是 5V 电平。重查第 3、4 节。

## 6. CAN 线束连接（CN1 / CN2）

两个 3 针绿色端子，引脚定义（从丝印面看，左→右）：

| 端子 | pin 1 | pin 2 | pin 3 |
| --- | --- | --- | --- |
| **CN1**（通道 1） | CANL1 | CANH1 | ISO_GND |
| **CN2**（通道 2） | CANL2 | CANH2 | ISO_GND |

**标准接线（接你的 CAN 设备/总线）：**

| 你的 CAN 线 | → | 接端子 |
| --- | --- | --- |
| CAN_H | → | **pin 2（CANHx）** |
| CAN_L | → | **pin 1（CANLx）** |
| CAN 地 / 屏蔽地 | → | **pin 3（ISO_GND）** |

> ⚠️ **ISO_GND 是隔离地**，和 USB 侧的 GND **不连通**（这就是 1500V 隔离的关键）。CAN 侧的参考地接 pin3 即可；不要把它和 USB 侧地短接，否则隔离失效。

**终端电阻（SW2）：**
- 板载 120Ω 终端电阻 R8/R9 由 **SW2（2 位琴键）** 切换。
- 本节点在**总线两端**时把对应通道的 SW2 拨到 **ON**；在**总线中间**时保持 **OFF**。
- 没接终端时，用万用表量 CANH↔CANL 应 ≈ **60Ω**（两端各 120Ω 并联）才正常通信；错误帧满屏多半是终端没接对。

## 7. 通信验收

- Windows：装 **PCAN‑View / TSMaster**，选识别到的 PCAN 设备，发一帧 `123#DEADBEEFCAFEBABE`。
- 自测：把同一通道的 CANH 与 CANL 短接（或接回环头），能收到自己发的回显 = 收发器 + 隔离器 + MCU 全通。
- Linux：`ip link` 应看到 `can0` / `can1`（SocketCAN）。

## 8. 常见故障速查

| 现象 | 先查 |
| --- | --- |
| 插 USB 没反应（无 PCAN 设备） | MCU 没起振（晶振≈1.6V）、QFN 桥锡、固件没烧成功 |
| 烧录 `No Response` | TX/RX 是否交叉、BOOT 按键有没有按住、串口是不是 3.3V |
| 3.3V 偏低/为 0 | 退耦短路 / LDO 方向 / 5V 没到 |
| CAN 发不出 | 隔离器方向、收发器 1 脚、CC 下拉 R10/R11 有没有焊 |
| 错误帧满屏 | SW2 终端没接、或 TX/RX 接反 |
| 隔离两端地导通（蜂鸣响） | U2 插件方向焊反 / 桥锡 |
| MCU 烫手 | QFN 内部短路，**立刻断电** |
