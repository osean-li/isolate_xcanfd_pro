# 外壳（3D 打印）

本目录存放板子外壳的 3D 模型，方便自己 3D 打印一个壳子把板子装起来。

- **`外壳.3mf`**：3MF 格式，可直接导入切片软件（PrusaSlicer / Bambu Studio / Cura 等）打印
- **`外壳.STEP`**：STEP 格式，可在 CAD 软件中查看 / 修改外形

## 组装提示（来自原项目）

- 面板文件可在原工程导出到立创面板下单（用于区分 CAN 通道的贴纸）
- 打印后，用烙铁或热熔方式在四角埋入 **4 颗 M3×4×4.2 铜螺母**
- 用 **M3×5 螺丝** 固定上下壳
- CAN 通道标识需要面板贴纸
