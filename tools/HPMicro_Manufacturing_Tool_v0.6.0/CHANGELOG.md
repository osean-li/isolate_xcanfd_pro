# HPM Manufacturing Tool Change Log

## v0.6.0           2025年05月30日
### 新增
1. 新增 HPM6P00、HPM5E00 系列的烧写及其它操作，新增 HPM6E00、HPM5E00 固件；
2. 新增 verify-checksum 及 query-rte command 两条命令支持；
3. 新增烧写并校验功能；
4. 新增内存视图标签页，支持内存读取并显示，
5. 新增镜像内存逐字节比较以及快速校验和比较功能；
6. 新增内存区域擦除以及整片擦除功能；
7. 新增量产命令配置镜像文件夹烧写功能；
8. OTP 标签页新增转换离线烧录器 HPMicro OBOX 配置功能；

### 优化
1. 优化导入导出配置，新增 HPMARC 导入导出配置类型；
2. 优化 OTP 写入后增加读写校验功能；
3. 优化配置量产包名称及路径参数未持久化问题；
4. 优化原子命令中部分长度只能输入十进制问题；
5. 优化镜像编辑部分长度参数只能输入十进制问题；
6. 优化固件烧写命令错误码信息；

### 修复
1. 修复工具在存在 OTP 字未连接设备进入 OTP 页导致的崩溃问题；
2. 修复导出量产包中文路径乱码问题；
3. 修复镜像编辑新建签名证书密码长度错误问题；
4. 修复部分输入框十六进制数组只能从最后删除的问题；


## v0.5.0           2024年11月29日
### 新增
1. 新增 USB-HID 使用自定义 VID，PID 连接功能；
2. 新增一键导入 csv/txt 格式的 OTP 配置功能；
3. 新增构建量产工具压缩包功能；
4. 新增量产压缩包设置密码功能；
5. 新增量产压缩包设置最大烧写次数功能；
6. 新增量产命令编辑、多选移除、移动命令等功能；
8. 新增镜像助手编辑命令容器镜像功能；
9. 新增镜像助手生成 SRK HASH 时同步生成 Bootloader 签名固件并拷贝证书信息功能；
10. 新增命令行模式命令支持设置超时时间功能；
11. 新增命令行模式自动检测连接设备功能；
12. 新增命令行模式参数实现自动加载 Bootloader 固件功能；
13. 新增命令行模式执行镜像编辑命令功能；

### 优化
1. 优化同步到量产命令功能，支持选择同步到 Open/Close 阶段；
2. 优化 OTP 存在待烧写字时工具提示信息；
3. 优化工具导入导出配置入口 UI 展示；
4. 优化镜像助手生成签名证书目录结构；
5. 优化镜像助手 SRK HASH/EXIP KEK 等信息同步到 OTP 写视图时提示信息；
6. 优化镜像助手部分编辑界面 UI 展示；
7. 优化镜像助手编辑 RAM 镜像时的容器头偏移默认值配置；

### 修复
1. 修复 HPM6E00 FLASH 配置中分组缺少第三组的问题；
2. 修复镜像助手识别 FLASH 配置字错误的问题；

### 已知问题
1. 在某些 SoC 下偶现命令容器镜像烧写后无法正常启动的情况；


## v0.4.1           2024年08月02日

1. 新增 Linux 平台支持，所有功能与 Windows 平台保持一致；
2. 更新 Boot Loader 固件，修复大镜像采用串口烧写速度较慢的问题；
3. 支持加载 Boot Loader 固件后，采用低波特率连接设备；
4. 调整连接设备波特率下拉框频率范围；
5. 修复 HPM6700 系列波特率调整后无法正常连接的问题；
6. 修复 GUI 和 CMD 模式下，使用 erase-chip 和 erase-region 命令在擦除大内存 FLASH 超时擦除失败的问题；
7. 修复了部分 SoC 下 OTP 模板参数错误的问题；
8. 修复部分 SoC 采用原子命令读取 FLASH 内容时，ID参数与地址不匹配时程序崩溃的问题；
9. 修复镜像编辑助手对于加密镜像仍然可以编辑的问题；
10. 修复镜像编辑助手自定义数据镜像无法正常生成的问题；
11. 修复镜像编辑助手取消勾选签名或加密窗口仍然会同步 OTP 字到开发工具的问题；


## v0.4.0           2024年05月22日

1. 新增 HPM6E00 系列的烧写及其它操作，新增 HPM6E00 固件；
2. 更新各个 SoC 固件，支持 FS-USB HUB； 
3. 更新开发模式导出导入批量配置功能，开发模式支持导入无锁版本配置；
4. 更新开发模式串口连接配置只放开频率设置，其余设置均禁用；
5. 更新开发模式 OTP 读视图下鼠标悬停时参数提示列表，与手册保持一致；
6. 修复开发模式下添加批量命令配置对话框原子命令配置错误问题；  
7. 修复开发模式下烧写时未检测到 FLASH 配置也正常烧写的问题；
8. 量产模式增加设置对话框，支持配置串口是否自动连接功能；
9. 更新命令行模式下，多个USB设备连接时没有提示的问题；


## v0.3.3           2024年01月26日

1. 新增了 HPM6800 连接以及EMMC配置烧写功能;
2. 新增了 HPM6700/HPM6400, HPM6300, HPM6200, HPM5300, HPM6800 固件包;
3. 新增工具连接设备时自动加载对应芯片固件包功能；
4. 修复了镜像助手在签名时偶现崩溃的问题；


## v0.3.0           2023年08月31日

1. 支持了 HPM5300 连接烧写功能；
2. OTP读视图增加了鼠标悬浮提示功能；
3. OTP写视图增加了用户配置数据持久化功能；
4. 修复了OTP烧写时先烧写第0字导致的问题；
5. 增加了烧写工具中锁定配置功能，当配置锁定后，该配置只能在量产模式打开，无法在开发模式查看，该功能是为了解决用户配置泄露的问题；
6. 量产工具增加了烧写错误提示；
7. 重构了镜像助手，左侧布局窗口取消了点击功能，右侧配置窗口改为流式布局并按模块进行划分；
8. 镜像助手增加了固件信息自动检测功能；
9. 镜像助手配置窗口每个模块增加了悬浮查看帮助信息功能；
10. HPM_MFG_TOOL 菜单栏镜像助手入口增加了限制逻辑并与镜像烧写标签页内部镜像助手入口同步；


## v0.2.0           2023年05月11日

1. 支持先楫HPM6700/6400系列，HPM6300系列，HPM6200系列芯片的配置及烧写；
2. 支持通过 USB-HID, 串口方式进行配置烧写；
3. 支持 FLASH 镜像，RAM 镜像及用户自定义数据的烧写；
4. 支持 FLASH 镜像，RAM 镜像及用户自定义数据的编辑，如添加FLASH、加头、加密（EXIP）、签名等； 
5. 支持 OTP 的读取和烧写，并提供了部分字段快捷烧写及 EXIP KEK 和 SRK HASH 的 OTP 烧写；
6. 原生支持先楫 ROM_HOST 原子命令，可用原子命令灵活组合指令序列进行烧写；
7. 支持快速同步生成量产工具烧写命令序列；
8. 支持命令行模式执行和烧写命令；
9. 量产工具支持通过USB-HID和串口多设备同时烧写；
10. 量产工具支持导入自定义配置；
11. 支持量产配置和日志文件加密功能；
